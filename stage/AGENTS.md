# Stage Plot and Input List

## Requirements

1. Can view in portrait or landscape layout
1. Can view on phone or desktop or printed to paper
1. Should use a comfortable amount of whitespace without being excessive
1. No single box on the stage plot should be significantly taller than another
1. Ireland should have the entire front of the stage to herself. Behind her should be the other instruments.
1. Ireland's full-width position should communicate placement without using excessive vertical space.
1. Printing should produce one landscape page containing the complete stage plot, input and patch list, and production notes without clipping.
1. Use the narrow horizontal gap between adjacent performer boxes as the reference spacing between stage elements that should not overlap; avoid larger vertical gaps between rows.
1. The Mike row should sit close to the Holly, Eric, and Andrew row with only the reference spacing between them.
1. The keys box should slightly overlap the bottom edges of both Holly and Eric.
1. The Ireland row should sit close to the keys and power row with only the reference spacing between them.
1. Ireland's microphone stand must not overlap Ireland's name or equipment description.
1. Ireland's microphone stand should be pinned to the bottom center inside Ireland's box.
1. Leave only a small reference-sized gap between the bottom of Ireland's box and the stage-orientation line.
1. Stage-element spacing, overlaps, and microphone placement must remain consistent in portrait, landscape, and print layouts.
1. In landscape, Mike's box should be the same height as the combined power and NEAT Split/XR18 stack beside it.
1. In landscape, the Holly, Eric, and Andrew boxes should use only enough vertical padding to present their labels clearly.
1. In landscape, the stage plot and patch-list panels should be only as tall as their content requires; any spare page height belongs outside the middle panels at the top and bottom of the page, not as empty space below the patch tables.
1. In landscape, the stage plot and input/patch-list panels must have equal outer heights; use modest vertical padding in the stage plot's blue boxes to fill the patch list's content-driven height.
1. In landscape, do not leave unused space between Ireland and the stage-orientation line; distribute that height as vertical padding within the blue stage boxes while preserving the required gaps and overlaps.
1. In landscape, the stage and patch panels should begin directly below the RED KARMA header; place surplus page whitespace below the content or above the title, not between the header and panels.
1. In portrait, Mike's box should be the same height as the combined power and NEAT Split/XR18 stack beside it.
1. In portrait production notes, Timing should appear directly beneath Band Provides.
1. In portrait, the gap below the Mike/equipment row must match the standard reference gap used between other non-overlapping stage elements.
1. In both portrait and landscape, keep the internal clearance between the Stage Plot heading and the first blue/equipment row to approximately half the former clearance; do not add unused whitespace above the stage elements.
1. In both portrait and landscape, center Ireland's name and equipment description together in the vertical space between the top of Ireland's box and the top of her microphone stand.
1. The Stage Plot heading should have the same top inset from its panel border as the Input & Patch List and Production Notes headings; adjusting this heading must not reposition any stage boxes.
1. In print, the stage/patch row and Production Notes should use their content height without a large empty band between them; any unavoidable spare height belongs at the bottom of the printed page.
1. In print, the NEAT Split/XR18 box must retain comfortable internal padding around all four lines of text.
1. In print, the XR18 IEM heading "DESTINATION TRANSMITTER" must remain on one line by using the available horizontal table space.
1. In print, allocate slightly less horizontal width to the stage plot and slightly more to the patch panel so "DESTINATION TRANSMITTER" remains fully visible across printer previews.
1. In print, the NEAT Split/XR18 text must stay fully inside its box with visible padding and must not collide with the POWER box above it.
1. In print, Ireland's name and equipment description must remain entirely above the microphone stand without touching or crossing it.
1. The Stage Plot panel and every element inside it must remain contained within the Stage Plot grid column in landscape and print layouts; they must never overlap or obscure the Input & Patch List panel.
